Linked Open Data

The tag layer, expressed in two standards that are not ours — so that other people's tools can read it without knowing anything about this project.

The short version. This project normalises a verbatim sentence in one discipline to a shared tag. A gazetteer project like MEHDIE or Kima normalises a place name in one language to a shared identifier. Same operation, different axis — so the same two standards fit both:
  • SKOS turns each tag into an addressable concept with a URI, labels in English and Hebrew, and a link to Wikidata.
  • W3C Web Annotation turns each grounded tag into an annotation whose target carries a TextQuoteSelector. That selector — exact, prefix, suffix — is this project's verbatim-grounding rule. The house rule turned out to be a W3C rule.

Scope — read this before comparing counts. This export is generated from the project's working corpus (187 records), which is larger than the frozen release corpus published at DATA/corpus.json (126 records) and uses a fuller schema. The two will not agree on totals, and are not meant to. Where a record has a published page the annotations target that page; where it does not, they target the paper's DOI. Two things this export deliberately does not contain. The reliability layer is private and is never published. And paper-level facets — discipline, method — are dcterms:subject statements about the paper, not annotations: they have no verbatim quote behind them, and only tags that do become annotations. Blurring that line would overstate what is grounded.

Reconciliation was not automatic, and says so

A link is only asserted when two things could be shown: a label or alias that matched, and a type statement licensing it. Where that failed, the result is recorded as unmatched rather than guessed. Place names needed a further step — Cambridge is two of the most important academic cities in the world, and no string test settles which one a paper means. Those were decided by hand, one at a time, with the reason recorded next to the decision, and one string ('Cambridge') had to be decided per paper rather than once. This is the same wall MEHDIE hits and answers with a reconciliation review interface.
