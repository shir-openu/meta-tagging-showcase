mechanismIncidental extraction of the pattern generates an anticipation of the next disk's location, which speeds responses when the anticipation is correct and slows them when it is violated— “Because of the hypothesized pattern-driven anticipations of the disks’ locations, RTs to last disks in Pattern sets (where pattern-based anticipations are veridical) should be faster than RTs to the last disks in Broken Pattern sets (where pattern-based anticipations are systematically misleading), with Control sets falling somewhere in…
mechanismConscious, intentional search for patterns produces frequent failures on the pattern-less majority of sets, and those failures interfere with the implicit extraction process— “Given the literature succinctly described above, the conscious search and its prominent failures are likely to interfere with the relevant implicit processes, and to diminish successful pattern extraction.”
mechanismDiscovering a pattern itself imposes a brief processing cost - an implicit 'aha' - that partly cancels the speedup it produces— “One possibility that comes to mind is that maybe there is an inherent slowdown upon the discovery of a pattern, as if the system takes a few milliseconds to develop an implicit “aha” experience.”
mechanismthe field's instruments are read as evidence about the field: every standard WM task is explicit, so the tasks record what researchers believe rather than test it— “We suggest to view these tasks as implicit, or indirect, measures of researchers’ beliefs regarding WM.”
mechanismthe question cannot be asked with the existing instruments because they presuppose its answer, so the paradigm has to be built before the experiment can exist— “Since existing WM tasks take as given that WM is predominantly conscious, they cannot be used to systematically address questions regarding the role of conscious awareness in WM.”
mechanisma functional definition is adopted deliberately, so that whether the new task counts as a working memory task is settled by what it requires rather than by precedent— “To answer this question we adopt a functional perspective. Thus, a working memory paradigm is a paradigm that taps the functions of WM.”
mechanismthe design forecloses statistical learning by construction: pattern-following and pattern-breaking endings are equiprobable, so learning history predicts chance on the critical disk— “Note, furthermore, that in each block we keep the probability of a pattern-following last move equal to the probability of a pattern breaking last move (=.5). Thus, one’s learning history during the experiment should lead to chance performance on the fifth disk.”
mechanismthe first block is analysed separately as the empirical version of the same argument, since each pattern has appeared only once and there is nothing yet to have learned— “Although we argued above that the paradigm precludes statistical learning per-se, analysis of the data of the first block is an important empirical test of this assumption.”

mechanismin the fourth study awareness is manipulated instead of measured, which converts a null result about awareness into a predicted dissociation— “Instead of measuring awareness and intention, it manipulates them.”
mechanismthe excluded participants are turned into a test: if awareness drove the effect it should be larger in those who noticed the patterns, and it is smaller— “The basic idea of this analysis is that if the effect of patterns depends on awareness then it should be stronger for the participants in the Excluded condition, who were conscious of (at least some of) the patterns. Yet, the data does not support this suggestion.”

If participants extract this other pattern, rather than the one we intended them to, then the fifth disk in pattern sets actually breaks the pattern thus transforming this set to a broken pattern set (and vice versa for the broken pattern sets). mechanismthe alternative account is not tested but reasoned through: imagine long-term memory doing this task, and it turns out to need the very operations attributed to working memory— “But these types of cognitive functions are usually attributed to WM (see Section 1.1), and parsimony suggests that we continue attributing them to WM, and not to LTM.”
mechanismstimulus position is jittered specifically to block a strategy that would let attention narrow to the local level and bypass the global stimulus— “This measure was taken to prevent participants from strategically narrowing their attention, thus focusing on the components of the numbers (the local dimension), rather than on the numbers themselves (the global dimension).”
mechanismthe fifth study changes the material from spatial to algebraic so the claim rests on the function rather than on the modality— “Unlike in the first four studies the patterns here were not visual. Rather, they were constituted from the relations between the numbers (e.g., X n +1 = X n + 2). In this sense, then, the patterns are conceptual in nature.”
