limitationfor many languages the available training corpora are only a few billion words or less (a data constraint) — “the existing corpora for many languages contain only a few billions of words or less”
limitationThe exact-match accuracy metric makes 100% unreachable because the models have no morphological information and synonyms count as errors. — “This also means that reaching 100% accuracy is likely to be impossible, as the current models do not have any input information about word morphology.”
limitationThe test set excludes multi-word entities. — “We have included in our test set only single token words, thus multi-word entities are not present (such as New York).”
limitationRelationship accuracy in the qualitative examples still leaves much room for improvement. — “As it can be seen, accuracy is quite good, although there is clearly a lot of room for further improvements”
limitationOn the Microsoft Sentence Completion Challenge the Skip-gram model alone is worse than LSA similarity; it only wins in combination with RNNLMs. — “While the Skip-gram model itself does not perform on this task better than LSA similarity, the scores from this model are complementary to scores obtained with RNNLMs, and a weighted combination leads to a new state of the art result 58.9% accuracy (59.2% on the development part of the set and 58.7% on the test part of the set).”
limitationThe benchmark's question count is combinatorial: questions are formed by pairing items from short hand-made lists, so the number of questions is far larger than the number of independent facts being tested. — “The questions in each category were created in two steps: first, a list of similar word pairs was created manually. Then, a large list of questions is formed by connecting two word pairs. For example, we made a list of 68 large American cities and the states they belong to, and formed about 2.5K questions by picking two word pairs at random”
limitationIn the semantic half of a semantic benchmark, a correct-meaning answer is scored wrong unless it is the exact expected token. — “Question is assumed to be correctly answered only if the closest word to the vector computed using the above method is exactly the same as the correct word in the question; synonyms are thus counted as mistakes”
limitationThe connection between the benchmark and any practical use is asserted as a belief, not shown. — “However, we believe that usefulness of the word vectors for certain applications should be positively correlated with this accuracy metric”
