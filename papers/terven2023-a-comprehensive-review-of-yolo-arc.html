mechanismAP is built on the precision-recall curve, and precision and recall trade against each other - detecting more objects raises recall and produces more false positives - so the single number is an area under a curve, not a count— “There is often a tradeoff between precision and recall; for example, increasing the number of detected objects (higher recall) can result in more false positives (lower precision).”
mechanismwhat counts as a correct detection at all is set by an IoU threshold, and COCO averages over a RANGE of thresholds from 0.5 to 0.95 - so the definition of `correct` is itself a parameter being averaged over— “It measures the overlap between the ground truth and predicted bounding boxes. The COCO benchmark considers multiple IoU thresholds to evaluate the model’s performance at different levels of localization accuracy.”
critiques cross-dataset comparison of object detection performance, since AP means a different computation on VOC and on COCO— “The differences in AP calculation make it hard to directly compare the performance of object detection models across the two datasets.”
supports the COCO AP as the current standard, on the ground that it evaluates localisation at a range of IoU thresholds rather than one— “This dataset includes 80 object categories and uses a more complex method for calculating AP.
