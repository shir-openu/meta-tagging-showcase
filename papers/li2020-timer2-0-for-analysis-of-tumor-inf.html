mechanismgene-signature methods score cell-type-specific gene sets INDEPENDENTLY per cell type; deconvolution methods model the tissue's expression as a WEIGHTED SUM of the component cells' profiles. Two different mathematical objects behind one output name— “Deconvolution methods define the problem as mathematical equations that model the gene expression of a tissue sample as the weighted sum of the expression profiles from the cells in the population mix”
critiques reliance on any single immune-infiltration algorithm, since the two families have variable performance advantages across cell types and tumours— “These two complementary categories of algorithms have demonstrated variable performance advantages in estimating specific immune cell types in different tumors.”
extends the original TIMER web server, which used one algorithm where this uses six— “Instead of just using one algorithm, TIMER2.0 ( http://timer.cistrome.org/ ) provides more robust estimation of immune infiltration levels for The Cancer Genome Atlas (TCGA) or user-provided tumor profiles using six state-of-the-art algorithms.”
