phenomenonperceptual (repetition) priming in monkeys
claim-typenull-result
transferfrom human memory research (human cognitive psychology): the human occluded-picture-naming priming paradigm is converted into a classification task so it can be run on monkeys — “As in priming studies in which humans were asked to name partially occluded images that they either had or had not seen previously ( Mitchell, 2006 ; Snodgrass & Feenan, 1990 ), we required monkeys to classify partially occluded photographs that they either had or had not seen previously.”
mechanismThe visual processing that supports recognition is encapsulated from the processing that supports classification, so remembering an image cannot feed forward to help classify a degraded version of it. — “This suggests that the visual processing necessary for recognition is cognitively encapsulated from that necessary for classification.”
mechanismPigeons and monkeys classify by different routes — local features versus global shape — which is offered as the explanation for why priming appeared in pigeons but not here. — “Thus, it appears that unlike our monkeys, pigeons are more likely to process local rather than global features in classifications tasks.”
relation — “Following Brodbeck (1997) , we trained rhesus monkeys ( Macaca mulatta ) to categorize photographs according to content (e.g., birds, fish, flowers, people).”
relation — “We failed to replicate the findings of the single study of priming in nonhumans ( Brodbeck, 1997 ).”
relation — “Given the short delays used (mean = 1.9 seconds), it is likely the monkeys would have recognized the primes and, thus, this study does not provide evidence for implicit priming in monkeys.”
differs inperceptual priming → search image — DURATION AND ATTENTIONAL DEPENDENCE - the search image is short lived and is diminished by divided attention, which is why the paper files it as short-term attentional priming rather than long-term perceptual priming — “short lived”
differs inpriming → explicit memory — WHETHER IT SURVIVES AMNESIA AND WHICH NEURAL SYSTEM CARRIES IT - the separation is the definition rather than a finding about it, which is what makes this record's null result awkward for the theory — “depends on neural systems distinct from those serving explicit memory”
effect directionrepetition suppression → priming — increases — “theorized to underlie priming”
differs inrecognition → classification — WHETHER MEMORY FOR AN IMAGE REACHES THE PROCESS AT ALL - the same remembered image supports recognition and does nothing for classification, which the paper reads as cognitive encapsulation between the two — “cognitively encapsulated”
replicationuntested
limitationThe study may simply have failed to identify the conditions under which priming would appear in monkeys. — “Third, priming could be a type of memory shared among humans, monkeys, and pigeons, but the current study was not designed appropriately to detect it.”
limitationDespite exploring many manipulations, the critical conditions for producing a memory effect on classification may have been missed. — “Although we based our methods on studies that have showed positive evidence of priming in humans and pigeons, and we explored a large number of reasonable manipulations, it is possible we failed to identify the critical conditions under which we would find priming, or indeed any memory effect on classification, in monkeys.”
limitationThe one significant priming effect obtained (Experiment 5, blur mask) is treated by the authors as unreliable and possibly a Type I error. — “Although the accuracy benefit seen with primed images was statistically significant, it should be interpreted with caution.”

content-observations: finding · quantity · variable · definition · key-term — grounded in the full text
findingAcross eleven experiments rhesus monkeys showed no priming: previously seen images conferred no reliable advantage when degraded versions had to be classified. — “Across 11 experiments, monkeys did not show priming, nor did they show any reliable benefit of having seen to-be-classified images.”
findingThe same monkeys did recognise the prime images, both masked and unmasked, at the same memory interval at which no priming appeared. — “In contrast, monkeys did recognize the primed images significantly above chance both when unmasked and when masked ( Figure 12 , right; unmasked: t (5) = 4.7, p < .01, d = 1.9; masked: t (5) = 4.4, p < .01, d = 1.8).”
findingThe single significant priming result (the blur-mask experiment) failed to replicate under stronger conditions and is interpreted as a Type I error. — “These results fail to replicate the memory effect observed in Experiment 5 under conditions in which the effect should have been strengthened, suggesting that the effect seen in Experiment 5 was a Type I error.”
findingShuffling the visible fragments of a masked image lowered classification accuracy, showing the monkeys used global arrangement rather than isolated local features. — “Scrambling the masked images significantly decreased classification accuracy compared to intact masked images ( Figure 11 ; t (5) = 5.2, p < .01, d = 2.1).”
findingThe classification was based on global form, exactly the kind of process that memory for the intact image should have facilitated. — “Together, these results indicate that the monkeys classified images based on global form, a process that would be expected to be facilitated by memory of the image.”
findingA close methodological replication of the only positive nonhuman priming study (in pigeons) produced no priming in monkeys. — “Under conditions similar to those in which pigeons showed a memory effect of having recently seen the to-be-classified stimuli ( Brodbeck, 1997 ), monkeys did not.”
findingThe combination of intact recognition with absent facilitation constitutes a dissociation between remembering an image and classifying it. — “Experiment 10 showed that monkeys remembered the primes sufficiently to recognize them while simultaneously showing no facilitation of classification.”
quantitysix — number of adult male rhesus monkeys tested throughout the study — “We tested six adult male rhesus monkeys ( Macaca mulatta ; mean age at start of testing = 3.2 years).”
quantity288 / 288 — primed and unprimed trials collected per monkey in Experiment 1 — “We ran twenty-four sessions, resulting in 288 primed trials and 288 unprimed trials for each monkey.”
quantity3.1% — the absolute accuracy advantage for primed images in the one experiment that reached significance, later attributed to Type I error — “It represents a relatively small absolute improvement (3.1%), and was the lone significant result of our study thus far.”
quantity80% / 81% — the occlusion level required in the pigeon-replication and the accuracy it produced — “Monkeys required the highest mask level, which occluded 80% of the image and brought performance down to 81% during phase 3.”
quantity98% — the monkeys' accuracy on the cats-versus-cars discrimination by the final training session — “Monkeys learned the cats/cars discrimination to over 80% accuracy by the end of the first training session and 98% accuracy by the final training session.”
quantityt (5) = 0.6, p = .6 — the null test of primed versus unprimed classification accuracy in Experiment 1, typical of the paper's null results — “Monkeys were not more accurate at classifying primed images than unprimed images ( Figure 3 , left; t (5) = 0.6, p = .6).”
