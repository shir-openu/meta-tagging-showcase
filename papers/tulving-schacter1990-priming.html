phenomenonpriming (implicit memory)— “Priming is a nonconscious form of human memory, which is concerned with perceptual identification of words and objects and which has only recently been recognized as separate from other forms of memory or memory systems.”
claim-typemechanism— “We believe that priming and perceptual identification are expressions of a single perceptual representation system (PRS), which exists separately from but interacts closely with other memory systems (10, 11).”
method — evidence— “The evidence we have reviewed converges on the PRS hypothesis-that is, priming reflects the enhancement of the neural computations and correlated cognitive operations of the perceptual representation system, PRS.”
mechanismpriming reflects a distinct perceptual representation system (PRS) - a pre-semantic, implicit memory that operates without conscious recollection, separate from but interacting with episodic and semantic memory— “Priming is a type of implicit memory; it does not involve explicit or conscious recollection of any previous experiences”mechanisms[0]
extends the authors' own earlier priming article (reference 9), which conjectured an as yet little understood memory system— “In an early article on priming, we conjectured that the effects we had observed might "reflect the operation of some ... as yet little understood memory system" other than semantic or episodic memory [p. 341 in (9)].”claim_relations[0]
builds-on Warrington and Weiskrantz's experiments on learning in densely amnesic patients (reference 4)— “One of the triggers for the study of priming turned out to be experiments by Warrington and Weiskrantz (4) showing that densely amnesic patients, who were severely impaired in their ability to remember recently seen information, exhibited near-normal learning when they were tested by methods that tapped what we now know is priming.”claim_relations[1]
contradicts processing theories of priming that treat memory as a unitary cognitive system (reference 49)— “These processing theories are usually based on a limited domain of data, such as cognitive psychology experiments with normal subjects.”claim_relations[2]

senseAND THE ARGUMENT FOR A NEW SYSTEM IS TAXONOMIC, NOT EXPERIMENTAL: `Priming resembles PROCEDURAL memory in that it enhances perceptual skills. senseAND THE UNAWARENESS IS OF THE MEMORY, NOT OF THE STIMULUS - WHICH IS A DIFFERENT CLAIM FROM EVERY MASKED-PRIMING RECORD HERE: `A person perceiving a familiar object is not aware that what is perceived is as much an expression of memory as it is of perception.` dehaene1998, Finkbeiner2011 and hesselmann2016 all work to make the STIMULUS unavailable to report.
