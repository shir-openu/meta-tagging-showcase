sensestyle - AS A CLASS IN A CLASSIFIER: the network's final layer has K outputs where K is the number of style classes, so here the word names a position in a label set rather than any property of the picture, and an image's style is whichever index wins— “into 3 fully collected layers sizes 1024, 512, K, respectively, where K is the number of style classes”
sensestyle ambiguity - AS POSTERIOR ENTROPY: the generator is rewarded for making the style classifier uncertain, so 'deviating from style norms' is implemented as producing images the classifier cannot place, and creativity becomes a property of a confusion matrix— “We added a style classification loss and a style ambiguity loss. Maximizing the stylistic ambiguity can be achieved by maximizing the style class posterior entropy”
sensenovelty - INHERITED FROM BERLYNE'S COLLATIVE VARIABLES: it is one of five arousal-raising properties named in an aesthetics theory - novelty, surprisingness, complexity, ambiguity and puzzlingness - and this system implements the fourth of them while the record's limitation says creativity was operationalised as the first— “Berlyne emphasized that the most significant arousal-raising properties for aesthetics are novelty, surprisingness, complexity, ambiguity, and puzzlingness. He coined the term collative variables to refer to these properties collectively”
