phenomenonreinforcement learning from raw visual input— “Learning to control agents directly from high-dimensional sensory inputs like vision and speech is one of the long-standing challenges of reinforcement learning (RL).”
claim-typemethod— “We present the first deep learning model to successfully learn control policies directly from high-dimensional sensory input using reinforcement learning.”
method — evidence— “The model is a convolutional neural network, trained with a variant of Q-learning, whose input is raw pixels and whose output is a value function estimating future rewards.”
transferfrom computer vision (convolutional neural networks): a convolutional network taking raw pixels as input, used as the function approximator for the action-value function in reinforcement learning— “The model is a convolutional neural network, trained with a variant of Q-learning, whose input is raw pixels and whose output is a value function estimating future rewards.”
mechanismexperience replay: store past transitions and train on random minibatches of them, breaking the correlations between consecutive experiences and stabilizing deep Q-learning— “randomizing the samples breaks these correlations and therefore reduces the variance of the updates”
builds-on convolutional neural networks + Q-learning— “The model is a convolutional neural network, trained with a variant of Q-learning”
builds-on Q-learning [26]— “The network is trained with a variant of the Q-learning [26] algorithm, with stochastic gradient descent to update the weights.”
builds-on the Arcade Learning Environment / Atari 2600 RL platform of [3]— “The use of the Atari 2600 emulator as a reinforcement learning platform was introduced by [3], who applied standard reinforcement learning algorithms with linear function approximation and generic visual features.”
extends neural fitted Q-learning (NFQ) [20] and its autoencoder variant [12]— “In contrast our approach applies reinforcement learning end-to-end, directly from the visual inputs; as a result it may learn features that are directly relevant to discriminating action-values.”
extends Q-learning combined with experience replay and a simple neural network [13]— “Q-learning has also previously been combined with experience replay and a simple neural network [13], but again starting with a low-dimensional state rather than raw visual inputs.”
sensethe reward - TRANSFORMED IN TRAINING, INTACT IN EVALUATION: positive rewards are fixed to 1 and negative to -1 while learning, and the agents are scored on the real unmodified games, so the signal the agent optimises and the number reported are two different quantities— “While we evaluated our agents on the real and unmodified games, we made one change to the reward structure of the games during training only. Since the scale of scores varies greatly from game to game, we fixed all positive rewards to be 1 and all negative rewards to be −1, leaving 0 rewards unchanged”
sensethe state - PARTIALLY OBSERVED AND PERCEPTUALLY ALIASED: the agent sees only the current screen, many emulator states look identical to it, and the paper states outright that the situation cannot be fully understood from one screen— “Since the agent only observes images of the current screen, the task is partially observed and many emulator states are perceptually aliased, i.e. it is impossible to fully understand the current situation from only the current screen”
senseprogress - MEASURED TWICE, AND THE SECOND MEASURE CHOSEN FOR LEGIBILITY: average total reward is the metric taken from the literature but is so noisy it suggests no steady progress, so the estimated action-value is reported as a more stable alternative— “Both averaged reward plots are indeed quite noisy, giving one the impression that the learning algorithm is not making steady progress. Another, more stable, metric is the policy’s estimated action-value function Q, which provides an estimate of how much discounted reward the agent can obtain by following its policy from any given state”
controlone set of hyperparameter values held constant across every game, with a single documented exception (k = 3, to make the lasers visible) — held — rules out per-game tuning - a score that reflects hyperparameters chosen for that game rather than a method that transfers across games— “We used k = 3 to make the lasers visible and this change was the only difference in hyperparameter values between any of the games.”
