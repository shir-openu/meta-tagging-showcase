transferfrom : The paradigm is modality-independent: the same binding effect and the same response-time modulation appear in visual, auditory and tactile versions, which the paper reads as evidence that the mechanism is central rather than perceptual — “Although mean response times modulate the effect, this modulation seems to be the same in previous visual, tactile, and auditory experiments (see Figure 4 ). These results also suggest that the effect evidences a rather central mechanism of action control.”
mechanismRe-encountering a stimulus that was bound into an event file retrieves the whole stored episode, including the response executed with it, so an ignored distractor can drive the current response. — “Re-encountering the stimulus of such an event file leads to a retrieval of the entire episode from memory, including the associated response 4-8 .”
mechanismRetrieval runs in parallel with the algorithm computing the required response, so the longer the response takes, the more often retrieval finishes in time to influence it - which is why slower tasks show larger binding effects. — “With longer lags between triggering response retrieval and execution of the response, the retrieval process is more likely to be completed before response execution 22 .”
mechanismInhibiting the same distractor twice in a row carries after-effects that facilitate the second inhibition, producing a benefit that is independent of whether the response repeats. — “That is, an inhibition account 1,25 would predict, that inhibiting the same stimulus two times in a row should always lead to benefits because after effects from distractor inhibition on the prime should facilitate distractor inhibition on the probe.”

content-observations: finding · quantity · variable · definition · key-term — grounded in the full text
findingRepeating a distractor speeds responding when the same response must be repeated, because the distractor retrieves a compatible response. — “If the same response has to be given on the prime and probe, distractor repetition leads to better performance as compared to distractor change because the distractor retrieves a compatible response.”
findingRepeating a distractor slows responding when the response must change, because the distractor retrieves the now-incompatible response. — “In contrast, if a change of response is required, repeating the distractor hampers responding as the distractor retrieves an incompatible response.”
findingThe paradigm's central advantage is that response retrieval shows up as the response-by-distractor interaction while distractor inhibition shows up as the distractor main effect, so the two mechanisms can be read off separately from the same design. — “While retrieval effects are evidenced by an interaction of response repetition and distractor repetition, distractor inhibition is measured as the main effect of distractor repetition.”
findingAcross 33 published experiments the binding effect grew larger as tasks got harder and mean response times got longer. — “The effects become larger with more difficult tasks and thus with longer response times.”
findingA single function describes how response time modulates the binding effect in visual, auditory and tactile experiments alike, implying a central rather than modality-specific mechanism. — “Note that this modulation can be represented by the same function for all modalities.”
findingThe interval between the prime response and probe onset must be short: no binding effect appeared at an onset asynchrony of 1,500 msec. — “No effect of distractor-response binding was found with an onset asynchrony of 1,500 msec 30 .”
findingPresenting target and distractor grouped together appears to be a precondition for the effect. — “Another prerequisite seems to be the presentation of target and distractor in a grouped fashion 19,21 .”
findingError rates usually carry no significant effects because participants commit too few errors. — “Yet, oftentimes, participants make very few errors and no significant effects are found in the error rates.”
findingShortening stimulus presentation to 300 msec, imposing an 800 msec response window, or varying the prime-probe gap between 150 and 350 msec all leave the result pattern intact. — “A response window of 800 msec does also not alter the result pattern 29 , and a variable period of 150 to 350 msec between prime response and probe onset has been used successfully, as well 28 .”
findingUnpublished data from participants with autism spectrum disorder suggest the effect is obtainable in a clinical sample with the same number of trials. — “Unpublished data of participants with autism spectrum disorder give a first indication that the effect of distractor-response binding can be found with similar trial numbers in a clinical sample.”
