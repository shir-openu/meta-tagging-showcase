However, the growing size of the GTDB bacterial reference treeterm·mth has resulted in GTDB-Tkterm·mth requiring substantial amounts of memory (∼320 GB) which limits its adoption and ease of use. These classifications are consistent with the GTDB framework and based on the same relative evolutionary divergence (RED)term·mth and average nucleotide identity (ANI) criteria for circumscribing taxa ( ParkspersName et al. , 2020 , 2022 ). A primary step in assigning classifications is placing genomes into the GTDB bacterial or archaeal reference trees using the maximum likelihood (ML) placement tool pplacerterm·mth ( Matsen et al. 2010 ). Unfortunately, ML placement with pplacer is a memory-intensive operation requiring ∼320 GB of RAM when using the GTDB R07-RS207 bacterial reference treeterm·mth comprised of 62 291 genomes. Adding to this challenge is the lack of favourable alternatives to pplacer as the EPA-ng ML placement method requires more memory than pplacer and distance-based methods such as APPLES-2 have inferior performance ( Balaban et al. , 2022 ; Barbera et al. , 2019 ; Koning et al. , 2021). The GTDB bacterial reference treeterm·mth has been growing rapidly in size with each GTDB release and is expected to grow by upwards of 30% per year for the next few years ( ParkspersName et al. , 2022 ). Placement of a genome with pplacer now consists of two steps. First, a genome is placed into a backbone treeterm·mth consisting of a single genome representative for each family (see Supplementary Methods ). If the genome is assigned to a class within this backbone treeterm·mth, it is then placed into a class-level subtreeterm·mth to obtain a more refined placement for the genome. The class-level subtreesterm·mth were constructed in a greedy manner with the maximum size of a class-level subtreeterm·mth being set based on the number of species representatives in the largest class ( Gammaproteobacteria with 9582 genomes in GTDB R07-RS207). Each class-level subtreeterm·mth was formed by selecting the largest class in the reference tree and traversing towards the root until the subtree contained at most 10 540 genomes (10% more than the Gammaproteobacteria ). This subtree was then pruned from the reference tree and the procedure repeated until all classes were assigned to a class-level subtreeterm·mth. For GTDB R07-RS207, this resulted in seven class-level trees. Each class-level subtreeterm·mth was then expanded to contain a single genome from each phylum in order to allow query genomesterm·mth to be placed as the most basal member of a class. A genome placed into a class-level subtreeterm·mth and assigned to a phylum belonging to one of the classes contained in the subtree is assigned the classification determined in the subtree.
