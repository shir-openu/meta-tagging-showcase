mechanismwhen noise correlation runs opposite to tuning similarity, a downstream reader can subtract the responses of dissimilarly tuned neurons, cancelling the shared noise while adding the signal, so the same spikes carry more information— “In contrast, negative relationships can improve population coding because common noise among dissimilarly tuned neurons can be subtracted, which strengthens the signal while dissipating the noise.”
mechanismlearning-driven changes to feed-forward synaptic weights (with excitatory-inhibitory noise cancellation) decorrelate similarly tuned neurons and preserve or increase correlation among dissimilarly tuned ones, producing the inverted correlation structure— “The plausibility of such circuitry is supported by a recent network model showing that learning-driven modulations to feed-forward synaptic weights yields decreased noise correlations for similarly tuned cortical neurons, and increased noise correlations for dissimilarly tuned neurons”
mechanismthe trigger for the correlation change is the learned stimulus-to-action mapping (the motif signalling which port to peck), not reward pairing, familiarity or exposure, which were equated across motif classes— “Thus, learning-dependent changes in the inter-neuronal correlation patterns depend on associations formed between stimuli and behavior, rather than experience, familiarity, or reward contingency.”
mechanismpositively correlated noise between similarly tuned neurons impairs coding because pooling cannot remove shared noise without removing signal— “Compared to independent noise, positively correlated noise between two similarly tuned neurons impairs encoding because no form of response pooling can attenuate the shared noise without simultaneously attenuating the signal”
mechanismpositively correlated noise between oppositely tuned neurons improves coding because subtraction removes noise and strengthens signal— “In contrast, positively correlated noise between two oppositely tuned neurons can improve encoding because subtracting one response from the other can both attenuate the shared noise and strengthen the signal”
mechanismtrial shuffling separates the contribution of single-neuron plasticity from that of correlation change, since it leaves individual responses untouched— “To distinguish these two sources of increased performance, we compared the classification performance without correlations (i.e. with trials shuffled, which does not alter individual neuron responses) to that with correlations intact.”
mechanismthe design equalises reward across all trained motifs so only the stimulus-response association differs— “All the motifs used during training were heard equally often in the context of the task and paired equally with reinforcement, but only the task-relevant motifs signaled the correct behavioral response on each trial. Thus, any effect of learning mediated directly by reinforcement should apply to all of the training motifs.”
