claim-typeexistence— “Here we show that scaling up language models greatly improves task-agnostic, few-shot performance, sometimes even reaching competitiveness with prior state-of-the-art finetuning approaches.”
method — evidence— “In this paper, we test this hypothesis by training a 175 billion parameter autoregressive language model, which we call GPT-3, and measuring its in-context learning abilities.”
transferfrom educational psychometrics: SAT analogy problems - 374 of them, an instrument built to test American secondary-school pupils - collected and used as a few-shot benchmark for a language model— “3.9.3 SAT Analogies To test GPT-3 on another task that is somewhat unusual relative to the typical distribution of text, we collected a set of 374 “SAT analogy” problems [TLBS03].”
mechanismin-context (few-shot) learning: a large pretrained language model performs a new task from a few demonstrations placed in its prompt, with no gradient updates - an ability that emerges from scale— “GPT-3 is applied without any gradient updates or fine-tuning, with tasks and few-shot demonstrations specified purely via text interaction with the model”
contradicts the fine-tuning paradigm (task-specific fine-tuning)— “GPT-3 is applied without any gradient updates or fine-tuning”
builds-on GPT-2 [RWC+19] and the Sparse Transformer [CGRS19]— “We use the same model and architecture as GPT-2 [RWC+19], including the modified initialization, pre-normalization, and reversible tokenization described therein, with the exception that we use alternating dense and locally banded sparse attention patterns in the layers of the transformer, similar to the Sparse Transformer [CGRS19].”
extends the in-context learning of [RWC+19] (GPT-2)— “Our use of in-context learning is also similar to [RWC+19], but in this work we systematically explore different settings for learning within the context.”
contradicts [BHT+20]'s argument that continuing to expand hardware and data sizes is not the path forward— “We find that path is still promising and in a zero-shot setting GPT-3 achieves 76% on LAMBADA, a gain of 8% over the previous state of the art.”
replicates the power-law scaling of language-model loss reported by [KMH+20]— “The power-law behavior observed in [KMH+20] continues for an additional two orders of magnitude with only small deviations from the predicted curve.”
extends the closed-book QA result of [RRS20]— “Their work suggests that even higher-capacity models could perform even better and we test this hypothesis with GPT-3.”
sensefew-shot - K demonstrations supplied at inference time as conditioning, with no weight updates; K typically 10 to 100— “Few-Shot (FS) is the term we will use in this work to refer to the setting where the model is given a few demonstrations of the task at inference time as conditioning [RWC+19], but no weight updates are allowed.”
senseone-shot - exactly one demonstration, distinguished not on performance grounds but because it matches how tasks are communicated to people— “One-Shot (1S) is the same as few-shot except that only one demonstration is allowed, in addition to a natural language description of the task, as shown in Figure 1. The reason to distinguish one-shot from few-shot and zero-shot (below) is that it most closely matches the way in which some tasks are communicated to humans.”
sensezero-shot - no demonstrations at all, only a natural language instruction; described as the most convenient and the most challenging setting— “Zero-Shot (0S) is the same as one-shot except that no demonstrations are allowed, and the model is only given a natural language instruction describing the task. This method provides maximum convenience, potential for robustness, and avoidance of spurious correlations (unless they occur very broadly across the large corpus of pre-training…
sensein-context learning - a term the authors introduce for the inner loop that occurs within a single forward pass, not for weight change— “We use the term “in-context learning” to describe the inner loop of this process, which occurs within the forward-pass upon each sequence.”
sense`zero-shot transfer` - A TERM RETIRED FOR A NAMED AMBIGUITY, WITH THE TWO READINGS SEPARATED: `the method is “zero-shot” IN THE SENSE THAT NO GRADIENT UPDATES ARE PERFORMED, but it often involves providing inference-time demonstrations to the model, SO IS NOT TRULY LEARNING FROM ZERO EXAMPLES.` **TWO DIFFERENT ZEROS** - zero weight updates and zero examples - collapsed into one word. The repair is a SPLIT: `meta-learning` for the outer structure and `in context-learning` for the inner loop, then `zero-`/`one-`/`few-shot` graded by demonstration count. NOT a redefinition; the old term is abandoned and its two senses are given separate names.— “In the context of language models this has sometimes been called “zero-shot transfer”, but this term is potentially ambiguous: the method is “zero-shot” in the sense that no gradient updates are performed, but it often involves providing inference-time demonstrations to the model, so is not truly learning from zero examples.
