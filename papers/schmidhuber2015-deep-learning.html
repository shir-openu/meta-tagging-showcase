sense`solution depth` / `problem depth` - A STIPULATIVE CASCADE THAT MAKES `DEPTH` WELL-DEFINED WHERE THE FIELD'S OWN BOUNDARY IS NOT. Three definitions in one breath: a `solution` is the set of used weights; the `solution depth` is the depth of the deepest CAP in that sequence; and the `problem depth` is `THE SMALLEST DEPTH OF ANY SOLUTION`. THE THIRD IS A MINIMUM OVER SOLUTIONS, NOT A PROPERTY OF A NETWORK - so two networks solving one problem can have different solution depths while the problem depth is a single number about the PROBLEM. This record already carries at `senses[1]` that experts could not agree where shallow ends and deep begins; this is the same author making the quantity precise by fiat instead of waiting for the field.— “Then the set of used weights is called a solution to the problem, and the depth of the deepest CAP within the sequence is called the solution depth. There may be other solutions (yielding different event sequences) with different depths. Given some fixed NN topology, the smallest depth of any solution is called the problem depth.”
