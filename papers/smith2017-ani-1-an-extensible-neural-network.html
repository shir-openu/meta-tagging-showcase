mechanismuntrained parameters reached only by larger inputs a sorted coulomb matrix sized for the largest training molecule leaves elements that are constant zero throughout training; a larger test molecule makes those elements non-zero, feeding values into network parameters that were never updated, so the output is arbitrary rather than merely inaccurate— “For baseline 1, this is caused by the coulomb matrix having elements which remain a constant zero throughout training, yet when a larger molecule is tested on it, those elements have non-zero values. These non-zero values are then fed into untrained network parameters, which yields arbitrary results.”
mechanismatom-type indistinguishability blocking learning symmetry functions that sum over all neighbours identically leave the network unable to tell a carbon from a hydrogen at a given distance, so the same vector element means different things in different molecules and training cannot resolve it— “For baseline 2, the problem comes from the fact that the AEVs have an inability to differentiate between atom types, creating confusion during the learning process.”
mechanismtrajectory bias in molecular-dynamics sampling MD follows one well-defined path across the potential surface, so a data set built from it is a sample of that path rather than of the surface; overcoming the bias requires a trajectory long enough to lose its own starting point— “Because of this, utilizing MD would follow a well-defined trajectory along the potential surface and would lead to sampling biased to the specific trajectory. Thus, a very long trajectory is required to overcome this bias.”
