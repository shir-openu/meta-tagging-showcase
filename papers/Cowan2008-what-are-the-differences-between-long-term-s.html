transferfrom industrial telegraphy and telephony: the practical demand that created the modern short-term memory task — operators holding rapid dot-dash series, then subscriber numbers — which the paper offers as the ecological source of the nonsense-syllable laboratory— “The nonsense syllables that Ebbinghaus had invented as a tool can be seen to have acquired more ecological validity in an industrial age with expanding information demands, perhaps highlighting the practical importance of primary memory in daily life.”
transferfrom neurophysiology (Hebb): the cell assembly, imported to give short-term memory a physical criterion independent of awareness— “One might relate short-term memory to a pattern of neural firing that represents a particular idea and one might consider the idea to be in short-term memory only when the firing pattern, or cell assembly, is active ( Hebb, 1949 ).”
transferfrom probability theory: the independence rule for a union of two events, S+L−SL, used to split a single recall probability into contributions from two stores— “This model assumes that, for any particular serial position within a list, the likelihood of successful short-term storage (S) and long-term storage (L) are independent, so that the likelihood of recalling the item is S+L−SL.”
mechanismShort-term memory arises as a temporarily activated subset of long-term memory, part of which falls within a capacity-limited focus of attention— “In this framework, short-term memory is derived from a temporarily activated subset of information in long-term memory.”
mechanismAttention freed by an undemanding distractor task is used for an attention-based rehearsal that refreshes items, so recall falls as the distractor rate consumes that attention— “The notion is that when the distracting task does not require attention, the freed-up attention allows an attention- based rehearsal of the items to be recalled.”
mechanismWorking memory tasks correlate with aptitude because preventing covert rehearsal forces reliance on attention-demanding storage and processing— “According to this view, what may be necessary for a working memory procedure to correlate well with cognitive aptitudes is that the task must prevent covert verbal rehearsal so that the participant must rely on more attention-demanding processing and/or storage to carry out the task.”
mechanismA post-perceptual mask overwrites sensory-specific features in activated memory, leaving only categorical information inside the attention-protected focus— “Presumably, the mask was capable of overwriting various types of sensory-specific features in activated memory, leaving behind only the more generic, categorical information present in the focus of attention, which presumably is protected from masking interference by the attention process.”
mechanismthe whole argument is organised as contamination control: for each claimed property of short-term memory, name the confounds that could produce the same result, then ask which studies defeated them— “To assess decay one must take into account, or overcome, contaminating effects of rehearsal, long-term retrieval, and temporal distinctiveness, which will be discussed one at a time in conjunction with evidence for and against decay.”
mechanisma nuisance parameter is varied by four-fold across two modalities and the limit does not move, which converts an ambiguous number into a capacity rather than a rate— “Given the striking differences between Sperling and Darwin et al. in the time period available for the transfer of information to a categorical form, the common four-item limit is best viewed as a capacity limit rather than a rate limit.”
mechanisma cross-modal additivity prediction is used as the test: if one store holds everything, two modalities together cannot exceed the larger single modality alone— “Moreover, if the cross-modality, capacity-limited store were the only type of storage used, then the sum of visual and auditory capacities in the dual-modality condition should be no greater than the larger of the two unimodal capacities (which happened to be the visual capacity).”
mechanismthe confound is designed out of the experiment rather than corrected for: one trial per participant, gathered by putting the laboratory in a shopping mall— “Baddeley and Scott (1971) set up a trailer in a shopping mall so that they could test a large number of participants for one trial each, so as to avoid proactive interference.”
