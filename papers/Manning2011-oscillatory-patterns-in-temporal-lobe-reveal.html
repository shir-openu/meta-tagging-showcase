claim-typeexistence— “Analyzing electrocorticographic recordings taken as 69 neurosurgical patients studied and recalled lists of words, we uncovered a neural signature of context reinstatement.”
method — evidence— “To test the context reinstatement hypothesis, we studied 69 neurosurgical patients who were implanted with subdural electrode arrays and depth electrodes during treatment for drug-resistant epilepsy.”
object of study — evidence— “We sought to determine whether context reinstatement may be observed in electrical signals recorded from the human brain during episodic recall.”
research question — evidence— “Although this behavioral evidence provides indirect support for context-based theories of memory, there is no direct neurophysiological evidence for contextual reinstatement.”
contribution — evidence— “Upon recalling a studied item, we found that the recorded patterns of brain activity were not only similar to the patterns observed when the item was studied, but were also similar to the patterns observed during study of neighboring list items, with similarity decreasing reliably with positional distance.”
transferfrom multivariate statistics: principal components analysis and the Kaiser criterion, used to turn thousands of correlated frequency-electrode measurements into a small orthogonal basis in which event-to-event similarity is preserved— “In this way, each component reflects a linear combination of the power in each frequency band across all recording electrodes, such that the pairwise neural similarities between events are preserved.”
transferfrom connectionist modelling: a 20-neuron simulated network, used not to model the brain but to derive what each competing account would predict for the lag profile— “Pattern of activations for a simulated 20-neuron neural network as a 15-item list is studied.”
transferfrom signal processing: the Hilbert transform on band-passed signals, with power computed across the whole session before segmentation specifically to avoid edge artifacts— “To reduce edge artifacts, we computed power at each frequency for the entire recording session before parsing the recordings into experimental events.”
mechanismRecalling an item revives the contextual state bound to it at study, and that retrieved context then cues other items encoded in similar contexts, which is what produces the contiguity effect.— “This retrieved context, in turn, activates other memories that were associated with similar contexts, producing the contiguity effect seen in recall tasks ( Fig. 4 B ).”
mechanismA slowly drifting contextual state becomes associated with each event as it is experienced, so that later recall of the event reinstates that state.— “These theories posit that a gradually changing contextual state becomes associated with each experienced event, and that recalling an event revives the contextual state associated with the original experience.”
mechanismcontext is operationalised by a property the theory predicts — slow drift — so the features analysed are exactly those that could carry a context signal— “we selected PCA-derived features from study events that showed significant positive autocorrelations ( Materials and Methods ), a defining feature of temporal context, for further analysis”
mechanismthe circularity that would create is blocked by splitting selection from test: the filter is fitted on study events only, and the hypothesis is tested on recall events— “To prevent selection bias, recall events were not used in the feature selection process.”
mechanismthe filter's cost is stated rather than hidden — removing content information also removes the forward asymmetry the behavioural effect shows, so a known feature of the phenomenon is invisible by construction— “In this way, if our feature selection framework filters out content information, one would not expect to see asymmetry in the neural data (further discussion is provided in SI Materials and Methods ).”
mechanismthe discriminating prediction is bidirectional decay: content reinstatement alone predicts a forward boost, autocorrelated noise predicts no lag structure, and only context predicts symmetric decay— “Of these three simulations, only the context reinstatement model predicts that neural similarity will decrease substantially with absolute lag in both the positive and negative directions, as observed in the neural data (further details and discussion are provided in SI Materials and Methods ).”
mechanismrival accounts are built and run rather than argued against — three neural network simulations using the same presented and recalled items as the real analysis
mechanismthe rehearsal alternative is tested through a consequence it would have elsewhere: if rehearsal drove the effect, neural contiguity should track the primacy effect, and it does not
mechanismindividual differences carry the inference: the same patients supply both the neural measure and the behavioural one, so the two can be correlated across people rather than compared as group means
