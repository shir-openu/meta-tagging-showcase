mechanismduring a short retention interval the lingering sensory trace and the rehearsed working-memory trace remain available in parallel, so the participant can answer from either, and the experimenter cannot attribute performance to one store— “With Retention Interval A, the participant could consult either the lingering ASM trace 1 or the rehearsed WM trace to decide whether the standard and comparison stimuli are the same or different; both memory traces exist in parallel.”
mechanismsensory memory keeps task performance intact when rehearsal is blocked, so a genuinely interfering secondary task can still yield a null result that is then misread as showing the two tasks use different mechanisms— “Even when the WM rehearsal mechanism for a stimulus has been blocked, task performance may remain partially or even fully intact due to contributions from ASM (e.g., McKeown et al., 2011 ).”
mechanismthe two memories run in parallel, so while the sensory trace survives, either one can drive the response and the experiment cannot tell which did— “The retention interval must extend beyond the persistence of ASM to isolate WM processes, because information about the most recently heard stimulus is simultaneously available to both ASM and WM (e.g., rehearsal) processes.”
mechanismthe convention arose from an early estimate that the sensory trace lasted about two seconds, which later work did not support— “Researchers initially speculated that the maximum duration of the ASM trace was about 2 s or less (e.g., Neisser, 1967 ; Crowder, 1976 ), which suggested that negligible contributions of ASM to memory performance could be assumed when intervals exceeded 2 s.”
mechanismthe verbal literature escaped the problem because serial recall lets primacy and recency separate rehearsal from the sensory trace; nonverbal sounds cannot be recalled aloud, so that separation is unavailable— “Nonverbal sounds typically are not amenable to recall tasks, because participants would need to respond verbally”

content-observations: finding · quantity · variable · definition · key-term — grounded in the full text
findingThe few-second retention intervals conventionally used in nonverbal auditory two-stimulus comparison tasks are too short to exclude sensory memory, so results credited to working-memory rehearsal may have been driven by the sensory trace instead.
findingPublished estimates of the duration of the auditory sensory trace disagree enormously, running from 2 s or less through 3.5 s, 4-5 s, 10 s, 10-15 s, 20 s and 30 s up to possibly 60 s.
findingRetention intervals under 5 s fall inside most published estimates of sensory-memory persistence, while intervals of 8-10 s or more begin to exceed most of them.
findingNo single safe retention interval can be recommended, because the duration of the sensory trace itself differs considerably from person to person.
findingWhite noise produced no suffix effect for either digits or tones, so the noise bursts researchers append to to-be-remembered sounds cannot be assumed to erase the sensory trace. the paper’s own words: “Greene and Samuel (1986) showed”
findingArticulatory suppression impaired memory for nonverbal sounds at a 6 s retention interval in one study but produced essentially no effect in a comparable study using 3 s and 12 s intervals. the paper’s own words: “Siedenburg and McAdams (2016) reported”
findingVerbal serial recall separates the two stores by serial position - primacy indexes rehearsal in working memory and auditory recency indexes sensory memory - a dissociation that nonverbal comparison tasks cannot deliver.
findingFour incompatible mechanisms are currently proposed for working memory of nonverbal sounds: the verbal phonological loop, a separate music memory loop, attention, and different mechanisms for pitch versus timbre.
findingThe comment attributes the field's contradictory results and its proliferation of rival theories to the conflation of sensory memory with working memory.
findingEstimates of how long auditory sensory memory lasts range from under 2 seconds to as much as 60 - the field disagrees with itself by a factor of thirty on the number the whole method depends on.
findingNeural evidence puts the sensory trace at up to 20 seconds or longer - far beyond the retention intervals in routine use. the paper’s own words: “Schröger (2007) concluded”
findingPublished studies have called retention of a sound 'working memory' after intervals as short as one second.
findingThe verbal working-memory literature did separate the two contributions; the nonverbal literature did not.

conceptauditory sensory memory — a passive, modality-specific, high-resolution store of just-heard sounds, of limited duration and independent of attention
conceptechoic memory — Neisser's name for the auditory sensory store; the paper states it is synonymous with auditory sensory memory
conceptworking memory — the active store that manipulates, rehearses and reinstates information, and interfaces with long-term memory
conceptshort-term store — Atkinson and Shiffrin's term, which the paper says became the working memory construct
conceptsensory register — the first of the three stores in the Atkinson and Shiffrin model
conceptretention interval — the gap between the two sounds during which the first must be held - the parameter that decides which memory the task measures
concepttwo-stimulus comparison tasks — the standard nonverbal paradigm: hear a sound, wait, hear another, judge same or different
conceptserial recall — the verbal paradigm in which list position lets rehearsal effects be separated from sensory ones
conceptmismatch negativity — an evoked neural response used as a measure of how long the auditory sensory trace lasts
conceptrehearsal — the active maintenance process that belongs to working memory and not to the sensory store
conceptauditory imagery — a sound reinstated from long-term memory without being heard - possible for working memory, impossible for the sensory store
