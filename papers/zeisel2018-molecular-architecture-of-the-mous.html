conceptastrocyte — the glial class that turned out to carry regional identity, split at a developmental boundary— “Thus, we have uncovered a diversity of astrocyte and ependymal cell types, showing the hallmarks of developmentally specified identities and regional specialization.”
conceptselectivity — the reciprocal of the number of clusters a gene set would annotate - the paper's own definition of how distinctive a marker is
conceptoligodendrocytes — the class that showed a LOSS of regional identity, against neurons and astrocytes which kept it
conceptgraph t-SNE — the authors' own coinage for a t-SNE variant that projects a KNN GRAPH rather than a distance matrix - named in the same sentence that introduces it
conceptstandard t-SNE — the unmodified algorithm, which acquires the qualifier `standard` ONLY because a variant now exists to contrast it with
conceptmultiscale KNN — the k-nearest-neighbour graph, built at multiple scales, that graph t-SNE projects in place of a distance matrix
conceptmarker gene set — given an explicit set-theoretic definition rather than a biological one: all expressed in the target cluster, NOT all expressed in any other
conceptPolished Louvain — the authors' name for Louvain community detection followed by a DBSCAN re-clustering pass - a coinage for a PIPELINE, not for an algorithm
concepttrinarization — the three-valued expressed / not-expressed / indeterminate call that the marker-gene-set definition is actually computed with
