limitationsThe distribution the method is supposed to learn cannot be characterised, so a finite set of collected instances silently becomes the definition of the problem class.
“This is unknown, and cannot even be mathematically characterized in an explicit way. Because we do not know what is in this distribution, we can only learn an algorithm that performs well on a finite set of TSPs sampled from this distribution (for instance, a set of historical instances collected by the company), thus implicitly incorporating the desired information about the distribution of instances”
what this limits: a claim that a learned CO algorithm solves a problem class: the true distribution is unknown and cannot be characterised explicitly, so what is learned is whatever a finite collected set - for instance a company's historical instances - happens to contain
