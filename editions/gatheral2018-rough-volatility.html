anything slower than exponential - and over time acquired the more precise meaning that the function is not integrable, and more precisely still that it decays as a power law with exponent less than one THE TECHNICAL SENSE IS DEFENDED AS THE ONLY ESTIMABLE ONE: the recent literature assumes long memory in the technical sense, and the authors add that meaningful results can probably ONLY be obtained under such a specification, since the asymptotic behaviour of the covariance function cannot be estimated without assuming a specific form for it THE QUESTION IS DECLARED UNANSWERABLE AS POSED, and the authors then supply a different instrument rather than a different answer: stated in terms of the asymptotic behaviour of the autocorrelation function the long memory question simply cannot be answered, but explicit expressions still allow the dependence structure to be analysed A WIDELY ACCEPTED STYLIZED FACT IS EXPLAINED AS AN ARTEFACT OF ITS OWN DETECTOR: the model has no long memory property, and yet the classical statistical procedures designed to detect volatility persistence TEND TO CONCLUDE THAT LONG MEMORY IS PRESENT in data the model generated the evidence for the stylized fact is dated rather than dismissed: the analyses supporting it use data that PREDATE high-frequency electronic trading, and the authors note the evidence has never satisfied the remaining doubters THE NEW NAME IS CHOSEN TO CARRY THE DEPARTURE: an existing model is adopted and renamed, with the new word picked to underline the single parameter inequality that separates it from its parent in the process used, ONE PARAMETER CONTROLS BOTH PROPERTIES AT ONCE -
