I tagged it `operationalised-as` and the gate refused: that type requires a MEASUREMENT OR DEFINITION cue, and it was right, because nothing here is measured. `same-as` is wrong too - a set of propositions and a set of worlds are different objects. A RENAMING INSIDE ONE FIELD, AND THE ONLY SENTENCE THAT STATES IT IS DAMAGED. The paper says the process `was sometimes called “local accommodation” but is now more usually termed “intermediate accommodation”` - and the staged text carries the page number 30 wedged inside the phrase, `termed “intermediate 30 accommodation”`. Quoted as an edge label that would read as a tagging error forever. `renamed-across-fields` is also the wrong type: this is one field renaming its own term, not a name crossing between fields. Evidence here is Berman's formulation instead, which states the process without naming it. A DAMAGED SENTENCE IS NOT THE ONLY SENTENCE - except when it is the only one that says the thing, and then the relation goes here.
