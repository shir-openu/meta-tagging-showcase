sensesA NAMED HYPOTHESIS GIVEN A BOUNDARY CONDITION RATHER THAN A VERDICT: `the AFFECTIVE PRIMACY HYPOTHESIS which predicts that affective information can be accessed automatically, preceding conscious cognition, HOLDS TRUE IN SUBLIMINAL PRIMING ONLY WHEN THE PRIMING IMAGE CONTAINS A FACE.` Not confirmed, not refuted - restricted. **And the condition is a property of the STIMULUS**, where Q-787's ambiguity condition is a property of the outcome situation and Holcomb2005's is a property of the observer. Three different places a priming effect can be conditional, and a corpus that records only `X primes Y` loses all three
