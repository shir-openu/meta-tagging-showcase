subliminal priming prime targets primes criteria same-different A generic same-different algorithm is applied unconsciously to the prime pair whatever its format, and the response it evokes then facilitates or interferes with the response demanded by the conscious target pair. If 'same' judgments are holistic and parallel while 'different' judgments are serial, then global-workspace theory predicts that only the parallel 'same' route can run without conscious access, so priming should come from same primes. Unconscious integration succeeds in this task because the stimuli fall within a sufficiently small spatial (and temporal) window and are of limited complexity. subliminal same-different (SD) task information integration fast-same effect criterion 1 for genuine unconscious processing (primes from large or novel sets) criterion 2 for genuine unconscious processing (different prime and target formats) review
